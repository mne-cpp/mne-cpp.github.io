mne_acq

Overview​

mne_acq lists, inspects, records and re-publishes acquisition sources from the command line. A source is named by the same URI that the acquisition library (mne::AcqDevice::open) takes, so anything that works in code works here.

Usage​

mne_acq list [--timeout s]
mne_acq info <uri>
mne_acq record <uri> <file.fif> [--duration s]
mne_acq stream <uri> --lsl [--name n] [--duration s]
mne_acq stream <uri> --brainflow-multicast <address:port> [--master-board id] [--duration s]
mne_acq view <uri> [--window s] [--duration s] [--screenshot file.png]

Commands​

CommandDescription
listPrints the registered URI schemes and the sources that answer within --timeout seconds (default 1), each with a URI ready for the other commands
info <uri>Opens the source and prints its backend, device and, per stream, the sample format, sampling rate, clock and every channel with its kind and unit
record <uri> <file.fif>Records the first stream of the source to a raw FIFF file (split into parts like MNE-Python above 2 GB), with trigger events in the stim channel and as annotations
stream <uri> --lslPublishes the first stream of the source as a Lab Streaming Layer outlet (float32, the stream's name unless --name is given)
view <uri>Shows the first stream as live traces in a sweep display: a fixed --window that the newest samples overwrite from left to right at the "now" marker, so the traces stand still; trigger events are marked until they are overwritten. Runs until the window is closed, --duration has passed or the source ends
stream <uri> --brainflow-multicastPublishes the first stream in BrainFlow's multicast format, so BrainFlow's STREAMING_BOARD in Python, C#, Julia or Java receives it (see below)

Options​

OptionDescription
--timeout <s>Seconds to search for sources (list)
--duration <s>Seconds to run (record, stream); 0, the default, runs until the source ends or Ctrl+C
--lslPublish as an LSL outlet (stream)
--name <n>Name of the published LSL stream (stream)
--window <s>Visible time window of view (default 10)
--screenshot <file.png>PNG of the view window when it closes
--brainflow-multicast <address:port>Publish in BrainFlow's multicast format to this group, e.g. 225.1.1.1:6677 (stream)
--master-board <id>BrainFlow board whose row layout is sent (stream; default -1, the synthetic board)
-h, --helpDisplays help
-v, --versionDisplays the version

Sources​

URISource
synthetic://?eeg=32&sfreq=1000Seeded synthetic oddball session
fiff:///data/sample_raw.fif?loop=1&speed=2Replay of a raw FIFF file, paced in real time
lsl://NAMEA Lab Streaming Layer stream by name
rtserver://127.0.0.1:4217?simfile=/data/run_raw.fifThe active connector of an mne_rt_server, here its FIFF file simulator replaying a file on the server's computer
brainflow://cyton?serial_port=/dev/ttyUSB0Any board BrainFlow supports, through an installed BrainFlow 5 (see below)
streaming_board://225.1.1.1:6677?board=cytonWhat a BrainFlow session streams with add_streamer, without BrainFlow (see below)
brainflow_file:///data/session.csv?board=cytonA file BrainFlow wrote, replayed without BrainFlow (see below)

The vendor amplifiers (eego://, natus://, babymeg://, ...) are listed by mne_acq list, each with its parameters.

BrainFlow Input​

brainflow://<board> opens a board through BrainFlow's BoardController library, which is loaded when the source is opened and is never part of MNE-CPP: library= names it, otherwise MNE_CPP_BRAINFLOW_LIB, then the library of pip install brainflow, then the system loader. BrainFlow 5 is required. The board is BrainFlow's id (-1) or name (synthetic, cyton_daisy, CYTON_DAISY_BOARD); the parameters are BrainFlow's input parameters (serial_port, mac_address, ip_address, ip_port, ip_protocol, other_info, timeout, serial_number, file, master_board, ...). Every row of the board becomes a channel in BrainFlow's units: EEG, EMG, ECG and EOG in microvolts (scaled to volts), temperature in degrees Celsius, the timestamp row in seconds since 1970. The timestamp row is the stream's clock, and a nonzero value in the marker row is an event.

mne_acq record "brainflow://cyton_daisy?serial_port=/dev/ttyUSB0" session_raw.fif --duration 60

A BrainFlow session in another program or on another computer can stream its board with board.add_streamer("streaming_board://225.1.1.1:6677"). streaming_board:// receives that stream without BrainFlow: the target is the same address and port (a multicast group is joined on the interface of the default route, as BrainFlow's STREAMING_BOARD does), and board= names the board behind the stream, whose row layout is needed to read it. The synthetic board, Cyton, Ganglion and Cyton + Daisy are known without BrainFlow; other boards need it installed. The channels are those of brainflow://, and the sender's markers are events (BrainFlow's own STREAMING_BOARD replaces them with its own). streaming_board://?simulate=1 streams a synthetic session in the board's layout to itself.

mne_acq record "streaming_board://225.1.1.1:6677?board=cyton" session_raw.fif --duration 60

Files BrainFlow wrote with its file streamer (add_streamer("file://session.csv:w")) or DataFilter.write_file hold a sample per line, the board's rows separated by tabs. brainflow_file:// replays them without BrainFlow, with the channels of brainflow://, the markers as events and the timestamps as clock; board= names the board that recorded the file. realtime=0 replays as fast as the samples are read, which converts a BrainFlow file to FIFF:

mne_acq record "brainflow_file:///data/session.csv?board=cyton&realtime=0" session_raw.fif

BrainFlow Output​

BrainFlow's STREAMING_BOARD interprets every packet with the row layout of a master board, so the publisher sends that layout: the source's channels fill the board's EEG rows in order (volts as microvolts, as BrainFlow reports EEG), the package row counts samples modulo 256 and the timestamp row holds Unix time. Channels beyond the board's EEG rows are not sent. The synthetic board, Cyton, Ganglion and Cyton + Daisy are known without BrainFlow; the layouts of other boards come from BrainFlow when it is installed (pip install brainflow, or MNE_CPP_BRAINFLOW_LIB pointing to its BoardController library). STREAMING_BOARD fills the marker row from its own insert_marker(). Both sides must use the same BRAINFLOW_BATCH_SIZE (default 3).

from brainflow.board_shim import BoardIds, BoardShim, BrainFlowInputParams

params = BrainFlowInputParams()
params.ip_address, params.ip_port = "225.1.1.1", 6677
params.master_board = BoardIds.SYNTHETIC_BOARD
board = BoardShim(BoardIds.STREAMING_BOARD, params)
board.prepare_session()
board.start_stream()

Exit Codes​

CodeMeaning
0Success
1Usage error (unknown command, missing argument, invalid number)
2The source could not be opened or read, or the output could not be written

Examples​

Record 60 s of a synthetic session and check the result in MNE-Python:

mne_acq record "synthetic://?eeg=32&sfreq=1000" session_raw.fif --duration 60
python -c "import mne; print(mne.io.read_raw_fif('session_raw.fif'))"

Re-publish a recorded file to LSL, e.g. for an LSL-based pipeline or LabRecorder:

mne_acq stream "fiff:///data/sample_audvis_raw.fif?loop=1" --lsl --name SampleMEG

Watch a FIFF replay live with a 5 s window:

mne_acq view "fiff:///data/sample_audvis_raw.fif?loop=1" --window 5

Inspect an LSL stream, then record it:

mne_acq list
mne_acq info lsl://SampleMEG
mne_acq record lsl://SampleMEG sample_copy_raw.fif --duration 30
