Acquisition Plugins in MNE Scan

Acquisition plugins (also called sensor plugins) are the entry point for all data in MNE Scan. They interface with hardware devices or data sources — EEG amplifiers, MEG systems, file readers, or simulated signals — and stream data into the real-time processing pipeline.

Plugin and Source​

An amplifier plugin is a thin layer over an acquisition source of the mne_acq library:

PartWhereResponsibilities
Pluginsrc/apps/mne_scan/plugins/<device>/, inherits AbstractSensorSetup widget and toolbar actions; builds the source URI from its settings; hands blocks to its output connector
Sourcesrc/libs/mne/acq/devices/<device>/, a scheme of AcqDeviceRegistry such as gusbamp://Talks to the vendor SDK in its own thread, writes the device's native samples, events and clock into a lock-free ring; measures impedances
Transport<device>_transport.h with <device>_driver_win32.cpp and <device>_simulator.cppThe vendor SDK as the source sees it; the simulator digitises a synthetic:// session in the SDK's format, so the source and plugin are tested on every platform without hardware

The source has no Qt dependency and works the same from any program, e.g. mne_acq or a test:

#include <mne/acq/acq_device.h>
#include <mne/acq/devices/acq_devices.h>

mne::register_gusbamp_scheme();
auto device = mne::AcqDevice::open("gusbamp://UB-1,UB-2?simulate=1&inputs=1-8&rate=512");
auto reader = device->stream().reader(mne::AcqReader::ReadMode::Lossless);
device->start();

Data Flow​

start() of the plugin opens the source, converts its stream description to a FiffInfo with mne::toFiffInfo(), creates a Lossless reader and starts the source and the plugin thread. The plugin thread reads blocks of the configured size in physical units with AcqReader::read() and passes them to its RealTimeMultiSampleArray. stop() interrupts the plugin thread and closes the source, which stops its acquisition thread and releases the device.

Key Classes​

ClassLocationPurpose
AbstractSensorsrc/apps/mne_scan/libs/scShared/Base class for all acquisition plugins
AcqDevice, AcqReadersrc/libs/mne/acq/Opens a source by URI; reads its stream
AcqBackendsrc/libs/mne/acq/Base class of a source; owns its streams and writers
PluginOutputDatasrc/apps/mne_scan/libs/scShared/Typed output connector that passes data to downstream plugins

Device Control​

While a source is open, a program can change its settings and run its commands without knowing the device: AcqDevice::controls() lists them as AcqControlInfo (parameters, commands and status values, each with type, unit, range and the states in which it may be used), read(), write() and invoke() take a control by id, and pollControlEvents() returns what changed: new values with the first sample they apply to, status updates, alerts and finished commands. A backend offers controls by overriding controls(), readControl(), writeControl() and invokeControl(), applies changes that affect samples at a block boundary, and reports with publishControlEvent(), which is safe on its acquisition thread. A change to how samples are scaled or named is also a new stream description version (AcqWriter::updateInfo()), valid from that sample on. synthetic:// shows all of it (gain, inject_event, refresh_info, samples).

Implementing a New Amplifier​

  1. Write the tests in src/tests/test_acq_devices/ against <device>://?simulate=1: stream layout, agreement with synthetic://, invalid parameters, a gating reader, and the error without hardware.
  2. Declare the transport in src/libs/mne/acq/devices/<device>/<device>_transport.h, write the simulator and the backend, and register the scheme in acq_devices.h.
  3. Implement the Windows driver: load the vendor DLL at run time from an absolute path with detail::AcqSharedLibrary, so the source builds without the SDK.
  4. Write the plugin: copy gusbamp or tmsi, build the URI from the settings, and add a test to test_mne_scan_plugins.
  5. Register the plugin in the parent CMakeLists.txt and, for static builds, in main.cpp via Q_IMPORT_PLUGIN.

See Creating a Plugin for the general plugin scaffolding guide.
