BrainViewCore

Namespace: mne::viz::qt  ·  Library: Visualization: Qt Backend  ·  Source: viz/backends/qt/3d/view/brainviewcore.h

#include <mne/viz/backends/qt/brainviewcore.h>

class mne::viz::qt::BrainViewCore

BrainViewCore is the Widgets-free part of the 3-D brain view.

It owns the scene state and the renderer and is driven by a BrainViewHost that forwards QtGui input events and frames.

Embed it through BrainView in a widget hierarchy, or through BrainWindow, a QWindow that widget applications embed with a window container (createWindowContainer()).

Widgets-free 3-D brain scene: model wiring, camera, multi-view, picking, overlay and QRhi frame recording.

from QRhiWidget::initialize(). Earlier GPU resources are dropped.

render(rhi, colorTexture, sampleCount, cb)​

Record one frame (3-D scene and 2-D overlay) into a colour texture.

The renderer is created on first use and keeps a clearing and a preserving render target on the texture.

Parameters:

  • rhi : *QRhi ** QRhi recording the frame.

  • colorTexture : *QRhiTexture ** Texture rendered into.

  • sampleCount : int Sample count of the pipelines.

  • cb : *QRhiCommandBuffer ** Command buffer of the current frame.

render(rhi, renderTarget, cb)​

Record one frame (3-D scene and 2-D overlay) into a render target owned by the caller, such as the current target of a QRhiSwapChain.

The renderer is created on first use.

Parameters:

  • rhi : *QRhi ** QRhi recording the frame.

  • renderTarget : *QRhiRenderTarget ** Target to clear and draw into; it must have a depth-stencil buffer.

  • cb : *QRhiCommandBuffer ** Command buffer of the current frame.
