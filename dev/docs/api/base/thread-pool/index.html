ThreadPool

Namespace: mne  ·  Library: Base Library  ·  Source: base/thread_pool.h

#include <mne/base/thread_pool.h>

class mne::ThreadPool

Runs tasks on a fixed set of worker threads.

parallel_for() and parallel_map() block until done, and the calling thread works through the range too, so they may be nested or called from a task of the same pool without deadlocking.

src/examples/ex_base/main.cpp
const std::vector<int> channels = {0, 1, 2, 3};
const std::vector<double> power = ThreadPool::global().parallel_map(channels, [](int ch) { return 0.5 * ch; }); // in order
auto background = ThreadPool::global().submit([] { return 42; });

Public Methods​

ThreadPool(threads)​

Starts the workers.

Parameters:

  • threads : std::size_t Number of workers; 0 for one per hardware thread.

~ThreadPool()​

Runs the tasks still queued, then joins the workers.

ThreadPool()​

operator=()​

thread_count()​

Returns:

  • std::size_t — The number of workers.

active_count()​

Returns:

  • std::size_t — The number of tasks that are queued or running; 0 once the pool is idle.

submit(task)​

Queues task.

Parameters:

  • task : F Callable without arguments.

Returns:

  • std::future< std::invoke_result_t< F > > — Its result, or the exception it threw.

parallel_for(begin, end, body)​

Calls body(i) for every i in [begin, end) and returns when all calls have finished.

Parameters:

  • begin : std::size_t First index.

  • end : std::size_t One past the last index; an empty range does nothing.

  • body : const std::function< void(std::size_t)> & Called once per index, from any thread.

parallel_map(input, f)​

Parameters:

  • input : const std::vector< T > & The values.

  • f : F Called once per value, from any thread.

Returns:

  • std::vector< std::invoke_result_t< F, const T & > > — f applied to every value of input, in the order of input.

Static Methods​

global()​

Returns:

  • ThreadPool & — The pool shared by the libraries, with one worker per hardware thread.
