TraceView

Namespace: mne::scene  ·  Library: Scene Library  ·  Source: scene/trace_view.h

#include <mne/scene/trace_view.h>

class mne::scene::TraceView

Viewport and interaction state of a raw-data trace view, without a GUI toolkit.

TraceView knows which samples and channel rows a view of a given size shows, handles pointer and wheel input (wheel zoom and scrolling, drag scrolling with inertia, the right-button ruler, annotation range selection and boundary resizing, the crosshair) and draws the overlays on top of the traces (crosshair, scalebars, ruler and annotation selection) into a Canvas. It does not animate or render traces: what the host has to do is reported through Effects, e.g. animate a scroll, change the cursor or redraw.

Positions are logical (device-independent) pixels with x = 0 at the left edge of the traces.
