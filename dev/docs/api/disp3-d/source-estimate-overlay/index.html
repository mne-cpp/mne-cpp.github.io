SourceEstimateOverlay

Namespace: DISP3DLIB  ·  Library: 3D Display Library

#include <disp3D/sourceestimateoverlay.h>

class DISP3DLIB::SourceEstimateOverlay

SourceEstimateOverlay manages source estimate data (.stc files) and applies colormap visualization to brain surfaces.

Color-mapped source estimate overlay that interpolates activation values onto a cortical surface mesh.

src/examples/ex_disp3d_scene/main.cpp
// Source estimate on vertices 0 and 2 only; the others stay cortex grey
MatrixXd activity(2, 1);
activity << 1.0, 0.1;
SourceEstimateOverlay sourceOverlay;
sourceOverlay.setStcData(InvSourceEstimate(activity, (VectorXi(2) << 0, 2).finished(), 0.0f, 0.001f), 0);
sourceOverlay.setThresholds(0.2f, 0.5f, 1.0f);
sourceOverlay.applyToSurface(&patch, 0); // no interpolation matrix: values land on their own vertices

computeInterpolationMatrix(surface, hemi, cancelDist)​

Compute interpolation matrix for a surface.

This spreads sparse source values to all surface vertices.

Parameters:

  • surface : *BrainSurface ** Pointer to the brain surface.

  • hemi : int Hemisphere index (0=lh, 1=rh).

  • cancelDist : double Cancel distance for interpolation (default 0.05m).

setThresholds(min, mid, max)​

Set threshold values for normalization.

Values below min are transparent, values above max are clamped.

Parameters:

  • min : float Minimum threshold.

  • mid : float Mid-point threshold (used for some colormaps).

  • max : float Maximum threshold.
