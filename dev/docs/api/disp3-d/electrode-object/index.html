ElectrodeObject

Namespace: DISP3DLIB  ·  Library: 3D Display Library  ·  Source: disp3D/renderable/electrodeobject.h

#include <disp3D/electrodeobject.h>

class DISP3DLIB::ElectrodeObject

Renderable sEEG / ECoG electrodes: contact spheres plus lead bodies.

src/examples/ex_disp3d_scene/main.cpp
QVector<IeegContact> shaft(4); // LH1..LH4, 3.5 mm apart: grouped into the sEEG depth lead "LH"
for (int k = 0; k < 4; ++k) {
    shaft[k].name = QString("LH%1").arg(k + 1);
    shaft[k].position = Eigen::Vector3f(0.010f + 0.0035f * float(k), -0.020f, 0.005f); // surface RAS, metres
}
ElectrodeObject electrodes; // a view of the implantation, drawn by BrainView::setElectrodes()
electrodes.setImplantation(IeegImplantation(shaft));
electrodes.selectContact("LH3");
float contactDistance = 0.0f;
const int pickedContact = electrodes.intersect(QVector3D(0.017f, -0.020f, 1.0f), QVector3D(0.0f, 0.0f, -1.0f), contactDistance);

setContactValues(values, colormap)​

Colour contacts by value through a colormap spanning [min(0, smallest), largest].

Contacts without a value keep the colour of their lead.

Parameters:

  • values : const QMap< QString, float > & Map of contact name -> scalar value.

  • colormap : const QString & ColorMap name.

clearContactValues()​

Restore the lead colours of all contacts.

surfaceColors(vertices, distance)​

Paint the contact values onto a surface, as MNE-Python's stc_near_sensors: each vertex takes the distance-weighted mean of the contacts within reach and fades out with the summed weight.

ECoG contacts are first moved onto the surface; depth contacts are not.

Parameters:

  • vertices : const Eigen::MatrixX3f & Surface vertex positions in the frame of the implantation, metres.

  • distance : double Reach of each contact in metres.

Returns:

  • QVector< uint32_t > — ABGR colour per vertex, transparent away from the contacts; empty without values.

src/examples/ex_disp3d_scene/main.cpp, line 139
ElectrodeObject electrodes; // a view of the implantation, drawn by BrainView::setElectrodes()
electrodes.setImplantation(IeegImplantation(shaft));
electrodes.selectContact("LH3");
float contactDistance = 0.0f;
const int pickedContact = electrodes.intersect(QVector3D(0.017f, -0.020f, 1.0f), QVector3D(0.0f, 0.0f, -1.0f), contactDistance);
ok &= expect(electrodes.totalContactCount() == 4 && electrodes.selectedContact() == "LH3" && electrodes.contactStreams().instanceCount == 4 && electrodes.bodyStreams().instanceCount == 1 && electrodes.contactLabel(pickedContact) == "LH3 (depth lead LH)",
             "ElectrodeObject: 4 contacts on one shaft, a ray through LH3 picks it");
