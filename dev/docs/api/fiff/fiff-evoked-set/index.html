FiffEvokedSet

Namespace: FIFFLIB  ·  Library: FIFF Library

#include <fiff/fiff_evoked_set.h>

class FIFFLIB::FiffEvokedSet

Set of FiffEvoked instances sharing one FiffInfo, plus channel-picking and compensation helpers.

The on-disk shape of a *-ave.fif: one FiffInfo and one FiffEvoked per FIFFB_EVOKED block (one per averaging condition). Conversion utilities pick channels and shift compensation state across the whole set in lock-step.

read(p_IODevice, p_FiffEvokedSet, baseline, proj)​

fiff_read_evoked

Wrapper for the FiffEvokedDataSet::read_evoked static function

Read one evoked data set

Parameters:

  • p_IODevice : QIODevice & An fiff IO device like a fiff QFile or QTCPSocket.

  • p_FiffEvokedSet : FiffEvokedSet & The read evoked data set.

  • baseline : QPair< float, float > The time interval to apply rescaling / baseline correction. If None do not apply it. If baseline is (a, b). the interval is between "a (s)" and "b (s)". If a is None the beginning of the data is used and if b is None then b is set to the end of the interval. If baseline is equal ot (None, None) all the time interval is used. If None, no correction is applied.

  • proj : bool Apply SSP projection vectors (optional, default = true).

Returns:

  • bool — true when successful, false otherwise.

computeGrandAverage(evokedSets)​

Compute a grand average across multiple evoked data sets.

Corresponding categories are averaged by summing data and dividing by the number of sets. The nave field accumulates the total count.

Parameters:

  • evokedSets : const QList< FiffEvokedSet > & List of evoked data sets to combine.

Returns:

  • FiffEvokedSet — The grand-average evoked set, or an empty set if input is empty.

computeAverages(raw, desc, events, log)​

Compute epoch-based averages from raw data according to an averaging description.

For each category in the description, matching events are epoched from the raw data, artifact-rejected, baseline-corrected, and averaged into a FiffEvoked entry.

Parameters:

  • raw : const FiffRawData & The raw data.

  • desc : const AverageDescription & The averaging description (categories, rejection, etc.).

  • events : const Eigen::MatrixXi & Event matrix (nEvents x 3): [sample, from, to].

  • log : QString & Processing log output.

Returns:

  • FiffEvokedSet — FiffEvokedSet containing one FiffEvoked per category, or empty set on failure.

subtractBaseline(epoch, bminSamp, bmaxSamp)​

Subtract baseline from each channel of an epoch.

For each row (channel), the mean of the samples in [bminSamp, bminSamp+nBase) is subtracted.

Parameters:

  • epoch : Eigen::MatrixXd & Data matrix (channels x samples) to correct in-place.

  • bminSamp : int First baseline sample (clamped to 0).

  • bmaxSamp : int Last baseline sample (clamped to epoch length - 1).
