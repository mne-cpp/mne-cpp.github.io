AcqDevice

Namespace: mne  ·  Library: Acquisition Library  ·  Source: acq/acq_device.h

#include <mne/acq/acq_device.h>

class mne::AcqDevice

An opened source.

Move-only handle that owns its backend.

src/examples/ex_acq_oddball/main.cpp
auto device = AcqDevice::open(uri);
if (!device) {
    std::fprintf(stderr, "Cannot open %s: %s\n", uri.c_str(), device.error().text().c_str());
    return 1;
}
const AcqStream stream = device->stream();
const auto info = stream.info();
// Electrode check before recording; amplifiers without an impedance mode return NotSupported.
if (auto impedances = device->measureImpedances()) {
    for (const AcqImpedance& z : *impedances) {
        if (z.ohms > kMaxImpedanceOhms) {
            std::printf("  check electrode %s: %.0f kOhm\n",
                        device->stream(z.stream).info()->channels[z.channel].name.c_str(), z.ohms * 1e-3);
        }
    }
} else if (impedances.error() != AcqErrorCode::NotSupported) {
    std::fprintf(stderr, "Impedance check failed: %s\n", impedances.error().text().c_str());
}
auto reader = stream.reader(AcqReader::ReadMode::Lossless);
if (!reader || !device->start().ok()) {
    std::fprintf(stderr, "Cannot start %s: %s\n", uri.c_str(), device->lastError().text().c_str());
    return 1;
}

start()​

Starts acquisition and output.

Returns:

  • AcqError — InvalidState unless Opened or Stopped, or the backend's error.

stop()​

Stops acquisition and output and joins the backend threads.

No-op unless Running.

Returns:

  • AcqError — The backend's error, or success.

close()​

Stops if needed and releases the device.

Idempotent.

measureImpedances(timeout)​

Measures the electrode impedances (control path, allocates).

Not while Running: amplifiers inject a test current for it.

Parameters:

  • timeout : std::chrono::milliseconds Maximum duration of the measurement.

Returns:

  • AcqExpected< std::vector< AcqImpedance > > — One entry per electrode channel, or InvalidState (Running, Failed, Closed), NotSupported (the device cannot measure impedances), or the backend's error.

lastError()​

Returns:

  • AcqError — The last error reported by the backend or a failed transition; success if none.

controls()​

The parameters, commands and status values the device offers (acq_control.h).

The list does not change while the device is open; an index into it names a control in AcqControlEvent::control.

Returns:

  • std::span< const AcqControlInfo > — The controls, empty for a device without any or a closed handle.

findControl(id)​

Parameters:

  • id : std::string_view Control id, e.g. "gain".

Returns:

  • std::optional< std::size_t > — Its index in controls(), or nothing.

read(id)​

Reads a parameter or status value (control path).

Parameters:

  • id : std::string_view Control id.

Returns:

  • AcqExpected< AcqValue > — The value, or InvalidParameter (no such parameter or status), InvalidState, NotSupported or the backend's error.

write(id, value)​

Sets a parameter (control path).

The type, range, options and the states in which it may be set are checked first; an integer is accepted for a number. A parameter that applies to samples takes effect at the next block and reports the first sample in its ValueChanged event.

Parameters:

  • id : std::string_view Control id.

  • value : const AcqValue & New value.

Returns:

  • AcqError — Success, or InvalidParameter, InvalidState or the backend's error.

invoke(id, arguments, timeout)​

Runs a command (control path) and waits for its result.

Parameters:

  • id : std::string_view Control id.

  • arguments : std::span< const AcqValue > Arguments in the order of AcqControlInfo::arguments.

  • timeout : std::chrono::milliseconds Longest time to wait for the device.

Returns:

  • AcqExpected< AcqValue > — The result (std::monostate for a command without one), or InvalidParameter, InvalidState, Timeout or the backend's error.

pollControlEvents(out)​

Takes the control events published since the last call, oldest first: value changes, status updates, alerts and finished commands.

Poll it regularly, e.g. from a user interface's timer; the queue holds 256 events and drops newer ones while it is full.

Parameters:

  • out : std::span< AcqControlEvent > Space for the events.

Returns:

  • std::size_t — The number of events written to out.

droppedControlEvents()​

Returns:

  • std::uint64_t — Control events dropped because nobody took them in time.
