AcqBackend

Namespace: mne  ·  Library: Acquisition Library  ·  Source: acq/acq_backend.h

#include <mne/acq/acq_backend.h>

class mne::AcqBackend

Base class of all backends.

Public Methods​

~AcqBackend()​

AcqBackend()​

operator=()​

description()​

Returns:

  • AcqDeviceDescription — Description of the opened device.

start()​

Starts acquisition and output.

Called in state Opened or Stopped.

Returns:

  • AcqError — Success, or the error that prevented the start.

stop()​

Stops and joins every backend thread before returning.

Called in state Running.

close()​

Releases the device.

Called once, after stop(). The default does nothing.

measureImpedances(timeout)​

Measures electrode impedances.

Called in state Opened or Stopped; the default returns NotSupported.

Parameters:

  • timeout : std::chrono::milliseconds Maximum duration of the measurement.

Returns:

  • AcqExpected< std::vector< AcqImpedance > > — One entry per measured electrode, or the error.

controls()​

The device's controls.

AcqDevice reads them once, when it takes the backend; indices into this list name the controls in the calls below and in AcqControlEvent::control. The default offers none.

Returns:

  • std::vector< AcqControlInfo > — The parameters, commands and status values of the device.

readControl(index)​

Reads a parameter or status value.

Control path; AcqDevice serializes the calls. The default returns NotSupported.

Parameters:

  • index : std::size_t Index into controls().

Returns:

  • AcqExpected< AcqValue > — The value, or the error.

writeControl(index, value)​

Sets a parameter.

AcqDevice has checked that it is writable now and that the value has the right type and range. A parameter that applies to samples takes effect at a block boundary and reports the first sample in its ValueChanged event. The default returns NotSupported.

Parameters:

  • index : std::size_t Index into controls().

  • value : const AcqValue & The new value.

Returns:

  • AcqError — Success, or the error.

invokeControl(index, arguments, timeout)​

Runs a command.

AcqDevice has checked that it may run now and the argument types. The default returns NotSupported.

Parameters:

  • index : std::size_t Index into controls().

  • arguments : std::span< const AcqValue > The arguments, in the order of AcqControlInfo::arguments.

  • timeout : std::chrono::milliseconds Longest time to wait for the device.

Returns:

  • AcqExpected< AcqValue > — The result, or the error.

streams()​

Returns:

  • std::span< const AcqStream > — The streams created while opening, in creation order.

Example​

No example of its own: Base class of device drivers; applications reach a backend only through AcqDevice::open().

It is exercised by:

src/examples/ex_acq_oddball/main.cpp
auto device = AcqDevice::open(uri);
if (!device) {
    std::fprintf(stderr, "Cannot open %s: %s\n", uri.c_str(), device.error().text().c_str());
    return 1;
}
const AcqStream stream = device->stream();
const auto info = stream.info();
// Electrode check before recording; amplifiers without an impedance mode return NotSupported.
if (auto impedances = device->measureImpedances()) {
    for (const AcqImpedance& z : *impedances) {
        if (z.ohms > kMaxImpedanceOhms) {
            std::printf("  check electrode %s: %.0f kOhm\n",
                        device->stream(z.stream).info()->channels[z.channel].name.c_str(), z.ohms * 1e-3);
        }
    }
} else if (impedances.error() != AcqErrorCode::NotSupported) {
    std::fprintf(stderr, "Impedance check failed: %s\n", impedances.error().text().c_str());
}
auto reader = stream.reader(AcqReader::ReadMode::Lossless);
if (!reader || !device->start().ok()) {
    std::fprintf(stderr, "Cannot start %s: %s\n", uri.c_str(), device->lastError().text().c_str());
    return 1;
}
